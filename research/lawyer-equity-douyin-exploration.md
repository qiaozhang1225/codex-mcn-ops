### 当前最重要的结论

这个领域具备传播空间，但不适合直接以“投融资律师”或“股权律师”作为主要内容入口。

用户不会因为想了解某个律师业务分类而停留。他们会因为以下问题停留：

- 和朋友合伙后，谁说了算；
- 自己出了钱，为什么股份反而更少；
- 合伙人中途退出，公司怎么办；
- 股权代持协议签了，为什么仍可能拿不回股权；
- 自己是小股东，如何防止被大股东架空；
- 公司公章、账户或法定代表人被别人控制后会发生什么；
- 创始人拿到融资后，为什么可能失去控制权；
- 对赌失败后，要不要回购投资人的股权。

因此，这个律师 IP 的大众传播入口应当是：

> 创业者和合伙人的股权、控制权与利益安全。

专业的股权设计、投融资协议和股权纠纷业务，应当作为解决方案承接，而不是作为视频标题的第一层表达。

## 四、15 条样本的文案结构拆解

这里不保存原作者完整逐字稿，只保留研究所需的短钩子、结构和可迁移逻辑。

### 1. 关系再好，也不能平均合伙

- 数据：808,087 赞；304,737 收藏；147,220 分享。
- 钩子：关系再好也不能这样合伙。
- 形式：三人对话式情景演绎。
- 结构：平均分股冲突 → 谁拥有决策权 → 亏损时怎么退出 → 盈利时如何竞业限制 → 利润预留。
- 起量原因：同时具备关系冲突、金钱数字、角色对抗和完整解决方案。
- 可迁移点：律师可以扮演“在签字前拦住合伙人”的角色，而不是坐着讲公司法。

### 2. 出钱与干活应该怎么分

- 数据：78,494 赞；107,006 收藏；收藏高于点赞。
- 钩子：两人合伙做生意，股份要这样分。
- 形式：具体人物、具体出资额、一步一步计算。
- 结构：60 万只出钱、40 万负责经营 → 资金股与人力股拆分 → 得出 36% 与 64%。
- 起量原因：用户能够立即代入自己的合伙关系，并把视频当作计算模板收藏。
- 风险：固定用 60% 资金股、40% 人力股并非通用法律答案，后续创作必须明确这是示例框架。

### 3. 股权代持的四份文件

- 数据：16,498 赞；11,133 收藏；9,381 分享。
- 钩子：只签代持协议，可能等于白签。
- 形式：先否定用户已有认知，再通过法院执行场景解释风险。
- 结构：代持是否合法 → 单份协议为什么不够 → 法院为什么可能不认可 → 四项证据链。
- 起量原因：用户以为自己已经安全，视频突然指出“你可能仍然拿不回股权”，损失恐惧非常强。
- 商业承接：代持结构审查、协议与证据链设计、代持纠纷。

### 4. 股份不是越分越少

- 数据：10,692 赞；2,509 收藏；3,705 分享。
- 钩子：股份是越分越多的。
- 形式：反常识观点配合公司利润、股份数量和投资人进入的连续计算。
- 结构：直接分比例的问题 → 引进人才后的稀释冲突 → 增量激励 → 增资扩股。
- 起量原因：标题直接挑战老板的直觉，并承诺一种“分出去但自己不吃亏”的方案。
- 风险：股份、股权、增资扩股和工商登记之间的关系容易被过度简化。

### 5. 为什么代持协议可能败诉

- 数据：3,351 赞；3,899 收藏；1,475 分享。
- 钩子：为什么签了代持协议还会败诉。
- 形式：税务、法院和股权恢复三个连续风险场景。
- 结构：协议合法不等于证据充分 → 恢复身份可能涉及转让和税费 → 四份文件 → 产品销售。
- 起量原因：比泛泛讲“代持有风险”更具体，直接回答“为什么会输”。
- 商业信号：文本工具包容易成交，但律师 IP 不应简单照搬低价模板售卖模式。

### 6. 被忽悠当挂名法人

- 数据：1,586 赞；540 评论；1,639 分享。
- 钩子：被忽悠当了公司法人怎么办。
- 形式：明确受害者身份，给出四步退出路径。
- 结构：巨额债务恐惧 → 协商 → 辞职 → 市监投诉 → 诉讼。
- 起量原因：点赞不高但评论和分享非常高，说明这是低频、高焦虑、强求助型需求。
- 商业承接：挂名法定代表人退出、登记纠纷、公司债务风险应对。

### 7. 平分股权为什么会让公司失控

- 数据：2,258 赞；1,945 收藏。
- 钩子：平分是最害人的股权结构。
- 形式：三人签约前的对话式冲突。
- 结构：决策僵局 → 亏损退出 → 盈利退出与竞业 → 风险准备金。
- 起量原因：法律机制被放入真实经营场景，观众不需要先理解专业名词。
- 可迁移点：可以形成固定栏目“签字前，律师再问你三个问题”。

### 8. 明星对赌故事

- 数据：4,479 赞；746 评论。
- 钩子：看似和资本对赌，其实已经进入资本的游戏。
- 形式：杨幂、张国立、冯小刚等公众人物案例串联。
- 结构：解释对赌 → 多个名人故事 → 失败代价 → 资本才是赢家。
- 起量原因：用名人降低了投融资知识的理解门槛。
- 局限：带来的是泛娱乐流量，不一定直接转化为企业法律客户。

### 9. 公章、账户与法定代表人至少控制一个

- 数据：3,152 赞；1,016 收藏；919 分享。
- 钩子：合伙开公司，账户、公章、法定代表人必须至少占一样。
- 形式：律师讲述真实求助故事。
- 结构：合伙人的婚姻变化 → 公司账户被冻结式失控 → 公章也不在手里 → 法定代表人也不是自己 → 只能诉讼。
- 起量原因：用一个看似无关的离婚事件，展示公司控制权如何瞬间崩塌。
- 可迁移点：这是最适合律师本人建立专业信任的形式之一。

### 10. 股权分配加五项合伙规则

- 数据：1,033 赞；1,193 收藏；655 分享。
- 钩子：两人合伙，股份这样分才合理。
- 结构：资金股与人力股计算 → 出钱、分工、分钱、管理、退出五项规则 → 五份协议。
- 起量原因：收藏高于点赞，说明观众把它当作开公司前的检查清单。
- 商业承接：合伙协议、章程、保密与退出机制的一揽子设计。

### 11. 动态股权与投资回收

- 数据：1,240 赞；731 收藏；713 分享。
- 钩子：两个人合伙开公司，股权应该怎么分。
- 结构：资金与人力贡献不对称 → 36%/64% → 投资回收期内动态分配 → 回收后恢复约定比例。
- 起量原因：比单一比例更接近真实利益协商。
- 风险：动态分配与工商登记股权不是同一个概念，需要律师补充协议效力、税务和执行边界。

### 12. 挂名法定代表人的控制方式

- 数据：1,317 赞；832 收藏。
- 钩子：老板不当法定代表人，就必须控制法定代表人。
- 结构：名章 → 职务权限 → 章程 → 印章证照。
- 起量原因：直接面向老板，给出可执行的控制清单。
- 文案问题：开头说“三件事”，正文实际列了四项，会损伤专业可信度。

### 13. 对赌协议的通俗解释

- 数据：1,834 赞；551 收藏。
- 钩子：对赌协议是创业者又爱又怕的双刃剑。
- 形式：用减肥打赌解释未来业绩承诺。
- 结构：生活类比 → 投资人和创始人的目标 → 双方风险 → 两类避坑提醒。
- 起量原因：理解成本低。
- 局限：传播中等，说明单纯“解释一个概念”不如冲突案例和损失结果。

### 14. 小股东被大股东长期欺负

- 数据：97 赞；92 收藏；72 分享。
- 钩子：小股东被长期欺负，不要一上来就起诉解散公司。
- 结构：否定错误动作 → 知情权与查账 → 请求合理价格收购 → 评估 → 最后才考虑解散。
- 专业价值：非常接近真实诉讼客户的决策路径。
- 流量弱点：标题专业、情绪不足、没有具体人物和损失数字。
- 机会：把同一法律路径改成“公司一年赚 500 万，大股东一分钱不分给你，你怎么退股”会更有传播性。

### 15. 股权转让是否需要其他股东同意

- 数据：114 赞；46 收藏；80 分享。
- 钩子：自己的股权，真的想卖给谁就卖给谁吗。
- 结构：资合与人合区别 → 对内转让 → 对外转让程序 → 优先购买权 → 登记受阻。
- 专业价值：知识准确度和业务相关度较高。
- 流量弱点：从抽象法律概念讲起，缺少具体交易受阻或损失场景。
- 机会：改写为“买家钱都准备好了，为什么其他股东一句话就让交易黄掉”。

## 五、爆款视频的共同逻辑

### 1. 冲突在前，法律在后

高表现视频通常不会先说“根据公司法第几条”，而是先告诉观众：

- 关系再好也不能平均分；
- 只签一份代持协议可能没用；
- 公章、账户、法人一个都不控制，最后可能什么都没有；
- 合伙人赚钱后离开，比亏钱退出更危险。

用户先识别自己的危险，再愿意听法律解释。

### 2. 用角色和数字替代抽象概念

强样本中反复出现：

- 两个人或三个人合伙；
- 一个人出 60 万，另一个人出 40 万并负责经营；
- 51%、36%、64%；
- 一块钱回购；
- 三年分期退出；
- 利润预留 30%。

数字不一定能直接成为标准答案，但它能显著降低理解成本。

### 3. 观众收藏的是“以后用得上”

多条样本的收藏数接近甚至超过点赞数。这说明用户不是把内容当作纯资讯，而是当作：

- 合伙前检查表；
- 协议清单；
- 股权计算模板；
- 出现纠纷后的处理路径。

对这个律师 IP 来说，收藏价值可能比情绪点赞更重要。

### 4. 对话和真实案件比坐讲更强

808,087 赞的头部样本采用多人对话，把决策权、退出和利润预留放入签合同的场景。潘律商业律师的样本则用一个真实求助故事展示公司失控。

这说明律师不一定要追求复杂拍摄，但至少要把内容组织成：

> 一个具体的人，在一个具体时刻，因为一个错误决定，可能损失什么。

### 5. 清单型内容天然适合商业承接

以下表达反复出现：

- 四个文件；
- 五项规则；
- 三个控制点；
- 两种退出方式。

这类内容既容易收藏，也容易自然承接协议审查、章程设计、股权方案和专项咨询。

### 6. 纯概念解释传播力有限

“什么是对赌协议”“股权转让程序”“投融资律师能做什么”等内容，即使专业正确，也容易停留在几百到一两千赞。

除非加入以下一种放大器：

- 公众人物或知名公司案例；
- 巨额损失；
- 创始人失去控制权；
- 合伙关系破裂；
- 一句话反常识结论。

## 六、初步受众画像

### 受众一：准备合伙创业的人

- 典型状态：朋友、夫妻、兄弟姐妹或业务伙伴准备开公司、开店。
- 核心问题：怎么分股、谁说了算、钱怎么分、有人退出怎么办。
- 内容需求：股权计算示例、合伙前检查清单、协议和章程边界。
- 潜在业务：股权设计、合伙协议、公司章程、控制权设计。

### 受众二：已经开始经营的创始人或实际控制人

- 典型状态：公司开始赚钱、引入团队或准备融资。
- 核心问题：如何激励但不失控，如何引入投资人，如何控制公章、账户和法定代表人。
- 内容需求：增资扩股、股权激励、控制权、融资条款。
- 潜在业务：股权架构、股权激励、融资专项法律服务。

### 受众三：关系已经恶化的股东

- 典型状态：被架空、不分红、查不到账、合伙人转移客户或资产。
- 核心问题：能不能退出、怎么查账、怎么要求回购、能不能解散公司。
- 内容需求：维权顺序、证据准备、谈判与诉讼路径。
- 潜在业务：股东知情权、股权回购、股东纠纷、公司解散。

### 受众四：被动承担公司风险的人

- 典型状态：挂名法定代表人、代持股东、员工或亲友替别人登记。
- 核心问题：怎么退出，债务会不会找上自己，原协议是否有效。
- 内容需求：风险判断、退出步骤、证据链。
- 潜在业务：登记纠纷、代持纠纷、法定代表人涤除或变更。

### 受众五：正在融资或签对赌的创业者

- 典型状态：需要资金，面对投资协议、回购和业绩承诺。
- 核心问题：哪些条款会让自己失去控制权，未达标后承担什么责任。
- 内容需求：投资条款翻译、对赌风险、控制权保护。
- 潜在业务：投资协议审查、融资谈判、对赌纠纷。

## 七、用户的核心需求与付费触发点

### 核心需求

1. 在关系还好时，把未来会翻脸的问题写清楚。
2. 确认自己对公司的真实控制力，而不只是名义持股比例。
3. 防止协议、代持或工商登记看似完整，实际无法执行。
4. 出现纠纷后，知道先做什么、后做什么，避免走错诉讼路径。
5. 把专业条款翻译成自己可能损失多少钱、股份或控制权。

### 付费触发点

- 即将与朋友合伙注册公司；
- 已经谈好投资人，准备签投资协议；
- 需要给核心员工或技术合伙人股份；
- 代持关系准备解除；
- 股东准备退出或已经闹翻；
- 公司不分红、不给查账；
- 公章、账户、营业执照或法定代表人失控；
- 收到回购要求或对赌未达标；
- 已经被起诉或准备起诉。

这些节点比泛泛的“企业常年法律顾问”更适合作为短视频咨询转化入口。

## 八、对 IP 定位的阶段性建议

当前不建议把账号直接定位成：

> 专业投融资与股权律师。

这个说法准确，但用户距离感强，也无法立即与自身问题对应。

更适合继续验证的定位是：

> 帮创业者在合伙、融资和股东纠纷中守住股权与控制权的律师。

或者更口语化：

> 专门帮老板解决合伙、股权和公司控制权问题的律师。

建议内容结构暂按以下比例验证：

- 50%：合伙冲突、控制权丢失、退出和翻脸场景；
- 30%：股权分配、代持、章程、协议和融资条款清单；
- 20%：真实纠纷处理路径，用于建立律师专业可信度。

这里仍是调研结论，不代表最终定位。下一步还需要验证：

- 律师本人最强的真实经验和典型案件；
- 他愿意长期讲哪些业务；
- 哪些业务客单价、交付能力和获客半径最匹配；
- 内容流量与真实咨询之间是否一致。

## 九、已验证与被否定的假设

### 已验证

- 股权与公司控制权并非天然低传播领域。
- 合伙冲突比“律师业务分类”更容易获得大众流量。
- 股权代持是兼具专业性、传播性和商业转化潜力的主题。
- 具体数字、清单和错误后果能显著提高收藏与分享。
- 律师真实案件叙事可以兼顾专业信任与传播。
- 小股东维权有真实需求，但需要从损失场景切入。

### 首轮被否定或削弱

- “投融资律师”不是有效的大众搜索入口。
- 只讲法律概念很难成为稳定爆款。
- 只靠点赞筛选会漏掉高收藏、高分享的强需求内容。
- “创始人被踢出局”这个表达在当前搜索接口中的召回不够精准。
- 长句关键词不一定比短场景词有效，可能直接触发接口失败。

## 十、风险与证据边界

1. 本轮只抓取每个关键词第一页，不代表抖音完整内容分布。
2. 搜索接口有召回漂移，例如“小股东如何保护自己”大量召回挂名法人内容。
3. “创业公司股权怎么分”接口失败，不能据此判断该主题没有内容。
4. 多个“宋老师”账号名称相近，尚不能确认是否为同一主体或矩阵账号。
5. 部分高流量内容把复杂股权问题简化为固定比例或固定文件数量，不能直接作为法律结论使用。
6. 涉及新《公司法》、司法解释、税务处理和工商登记的内容，正式创作前必须逐条核验时效与适用条件。
7. 明星对赌案例能够带来流量，但其受众未必转化为企业客户，需要与创业者真实案例分开评估。
