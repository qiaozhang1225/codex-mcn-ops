# 思成说 Recent Creation Memory

- 当前重点方向：财运、事业、玄学、磁场、命理咨询获客。
- 避免连续多条都写成“人生大道理”或“修心泛论”。
- 已确认纠偏：短口播优先 300-500 字，保留爆款开头钩子，结尾软咨询转化。
- 最新长度纠偏：不要为了卡字数把自然口播压成别扭短句。字数范围是表达安全区，不是压缩目标；顺滑、清楚、能说出口优先。
- 最新受众约束：思丞说更面向年龄稍微偏大的中年女性群体；后续选题优先财运、命运、事业、贵人运，默认避开情爱、爱情、恋爱技巧类主题。
- 最新替换经验：当一条文案失败是因为底稿/主题过于抽象或不接地气时，不要继续在旧稿上补丁式润色；应回到最新素材池重新选更具体的底稿，完整重跑二创流程。
- 最新素材厚度经验：厚度不是指有没有传播钩子、自查机制或例子，而是指原文是否有可缩减余量。二创大多以缩减为主；如果原文已经很短、几乎没有可删可压缩空间，忠实改写会太短，而写长又只能靠自行扩充或强行升华，就不适合作为主二创底稿，应标记为参考材料或重新选材。

### 内容组合原则

- 内容迭代采用双轨制：一条轨道利用当前账号已有数据继续优化，另一条轨道系统性探索账号尚未充分尝试的新方向。
- 没有账号历史数据只代表“未经验证”，不代表“不适合”或“不应占配额”。不得因历史样本缺失固化选题定式。
- 第 5 期共 24 条：已有方向迭代 16 条，新方向探索 8 条。
- 当前配比：现实贵人 3 条；玄学专业知识拆解 4 条；财运 / 磁场 / 漏财边界 5 条；道德经 / 易经现实解释 4 条；福报 4 条；苦难 4 条。
- 玄学专业知识拆解以「天乙贵人」为已跑出正向信号的起点，继续测试神煞、日主等复杂四柱知识的单点拆解；每条只讲一个概念，并提供普通观众能理解、能核对的判断入口。
- 福报与苦难各保留 4 条，目的是形成可比较的小样本，而不是用一条视频决定方向成败。

### 内部文案结构

- 默认采用“诊断—证据—机制—行动”：0—3 秒具体诊断，3—10 秒交付第一条证据，10—35 秒给现实场景，35—50 秒解释国学或命理机制，结尾只保留一个自然动作。
- 抖音优先制作 35—50 秒高密度版本；视频号可保留 50—70 秒完整解释。不同平台版本分别评估。
- 正文先让观众认出自己的现实处境，再解释玄学或国学机制；禁止先铺垫概念、经典背景或泛泛人生道理。

### 内部钩子优先级

1. 自查诊断：点明目标人群、现实问题和可核对信号。
2. 反常识判断：必须在正文中兑现反差，不能只有标题悬念。
3. 现实损失：优先连接钱、事业、熟人边界、客户或家庭责任。
4. 身份识别：让目标观众判断“我是不是这种人”。
5. 具体问题：问题必须直接关联现实处境，避免抽象概念提问。

“只有运气好的人才能刷到”一类幸运钩子可作为少量测试，不作为固定模板，避免持续消耗老师型 IP 的可信度。

### 内部验证方法

- 每条视频在 D1 / D3 / D7 固定记录播放、2 秒跳出、平均播放时长、完播、收藏、分享、主页访问和吸粉。
- 同一轮对照只改变一个主要变量；比较时控制平台、发布后时长、视频时长、内容形式、CTA 和发布时间段。
- 抖音阶段性观察目标：2 秒跳出低于 40%，平均播放时长达到 18 秒以上，高意向作品每千次播放吸粉达到 5 以上。以上是账号内部迭代目标，不是平台通用阈值。
- 视频号阶段性观察目标：同类作品完播率达到 20% 以上、平均播放 30 秒以上；不与抖音完播率直接比较。
- 同一方向至少形成 3—4 条样本后再判断主题；新方向不能因首条未跑出而直接停止。
