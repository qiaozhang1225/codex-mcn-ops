# 思成说 Creation Playbook

本文件只定义思成说相对于全局二创方法的差异，不提供固定文案模板。

## 角色与受众

- IP 是面向咨询意愿的玄学知识型角色，核心关注财运、事业、命理、磁场、贵人和现实处境。
- 受众以对财富、事业、家庭责任和人生选择敏感的中年女性为主。
- 说话姿态像老师当面提醒：直接、接地气、有判断，但不恐吓、不承诺结果。

## 内容选择

- 优先选择本身已具备财运、事业、命运、贵人、机会或现实损失入口的素材。
- 关系和修行主题只有在能自然连接到主体性、边界、事业、财富或现实选择时才适配。
- 佛学来源可以借鉴底层含义，但表达应与思成说的道家、国学和现实生活语境兼容。
- 如果素材只有抽象哲理，或必须新增一套处世结论才能适配，应重新选材。

## 内容组合与探索

- 每期同时包含“已有数据方向的迭代”和“尚未充分尝试的新方向探索”，不能只围绕历史胜出主题固化内容边界。
- 当前账号没有某一主题的数据时，将其标记为“未经验证”，而不是“不适配”。可结合 IP 定位、外部市场证据和咨询目标决定是否进入探索配额。
- 新方向需要形成可比较的小样本；原则上使用 3—4 条不同机制的内容完成首轮验证，避免用单条结果决定整个主题。
- 已验证方向负责稳定表现和承接账号定位，新方向负责寻找增量；两者必须在每期配比中分别标明。

## 主题分类规则

- 按内容机制分类，不按标题中出现的字面词归类。标题含“贵人”不代表一定属于现实贵人主题。
- “现实贵人”讨论人际互动、被帮助条件、说话方式、边界和现实处境，属于生活判断类内容。
- “天乙贵人”属于玄学专业知识拆解类：以神煞、日主、十神、五行关系等四柱概念为知识对象，将一个复杂概念拆成普通观众能快速理解和核对的单点内容。
- 某个专业知识点跑出正向信号后，应扩大验证同一内容机制下的相邻知识点，而不是仅围绕原词重复改写，也不能把结果错误归因到字面相近的泛主题。

## 传播与权威

- 优先保护源素材中的稀缺感、命运感、身份判断、反差和权威判断。
- 权威感来自对用户处境的判断与解释，不要求每条固定使用卦师、命理师或师父等身份标签。
- 玄学词汇可以承载用户熟悉的意义，但正文要让观众看见与现实处境的联系，不能只堆概念。
- 不为了显得接地气而把每条内容都改成生活清单，也不为了显得高深而写成空泛说教。

## 转化原则

- CTA 是可选的，取决于正文是否自然产生下一步咨询、评论、自查或收藏价值。
- 互动只选择一个主要动作，并请求完成下一步所需的最少信息。
- 诊断性内容可以承接低敏感度的自我信息；非诊断内容不机械索要生日、照片或关键词。
- 不以硬私信、隐私暴露或多重动作换取转化。

## 风险与表达

- 不保证发财、改命、转运、事业结果或即时见效。
- 不把边缘玄学词汇自动视为风险；风险清理仍按全局阶段做局部判断。
- 不依赖缺少知识内核的仪式动作。
- 长度区间只约束交付，不得迫使薄素材扩写、堆观点或强行升华。

## 验收

成稿应保留源机制、符合思成说受众、具有可感知的现实价值、口播自然，并让转化动作与正文价值相匹配。
