# 宋立心理第 8 条文案核心逻辑修正设计

## 目标

恢复原素材已经成立的核心命题：抑郁的孩子像是在逼父母把自己当成小孩重新养一遍。二创只能转换叙述视角、补足解释和安全边界，不能把“别把症状当态度”提升为新的中心论点。

## 内容契约

1. 开头直接保留“抑郁的孩子其实是在逼爸妈做一件事”的悬念，并在同一句揭示“把他当成小孩重新养一遍”。
2. 将原素材中 16 岁女孩的第一人称自述转换为宋立老师讲述的案例，保留锁门、少吃、不洗漱、游戏、撬锁和自伤等画面。
3. 主体正面解释“重新养一遍”：重新提供回应、理解、肯定、安全感和基本生活能力支持。
4. “不要把行为简单看成懒惰或对抗”只能作为解释案例的从属内容，不能取代原始命题。
5. 专业评估、治疗和危机干预是必要边界，但不能改写或否定“重新养一遍”的内容任务。
6. 最终口播正文保持在宋立老师当前 380–480 字的长度范围内。

## 明确排除

- 不再使用“不是把他当婴儿重新养一遍”这类直接否定原命题的表达。
- 不把医学风险清理变成另一个创作主题。
- 不承诺康复结果，不把家庭支持描述成专业治疗的替代品。

## 验收

- 开头、主体和结尾都围绕“重新养一遍”展开。
- 正文按不计空白字符统计为 380–480 字。
- 本地首轮交付、创作任务数据库和飞书第 8 条内容一致。
- 飞书只精准修改第 8 条，不影响第 9 条及其他章节。
